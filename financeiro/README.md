# Departamento: Financeiro

## Objetivo
Gerenciar a saúde financeira da Tecno IT, controlando fluxo de caixa, pagamentos, recebimentos, e viabilizando orçamentos para tecnologia e inovação.

## Estrutura de Squads (AIOS)
Este departamento recebe suporte de agentes focados em análise de dados operacionais (ex: `@analyst`) para projeções financeiras e faturamento.
