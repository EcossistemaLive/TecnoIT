Gestão de Risco

Riscos ativos e mitigações

Médio
Firestore ainda nos whatsapp_handlers
Os handlers de WhatsApp ainda importam firestore_db para rate limiting, dados de participantes e sessões JWT.
→ Migrar para PostgreSQL + Redis na Semana 2
Médio
Aprovação Meta for Developers: 2–5 dias úteis
Número WhatsApp precisa ser verificado e app aprovado pela Meta antes do deploy funcionar em produção.
→ Iniciar cadastro imediatamente — não bloqueia outras semanas
Baixo
Supabase free tier pausa após 1 semana sem uso
Inatividade por 7+ dias causa pausa do projeto. Retoma automaticamente no primeiro request.
→ Health-check diário pré-evento ou upgrade para Pro ($25/mês)
Baixo
Claude API: créditos no workspace atual
API key configurada mas workspace pode precisar de créditos adicionais para Cat. A em produção.
→ Verificar saldo em console.anthropic.com antes do evento
