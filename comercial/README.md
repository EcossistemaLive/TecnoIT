# Departamento: Comercial e Vendas

## Objetivo
Estruturar o relacionamento, prospectar, qualificar leads e fechar projetos estratégicos para a Tecno IT, garantindo uma transição fluida para a operação.

## Estrutura de Squads (AIOS)
- **live-operations:** Consultores de fechamento, mapeamento RAG em drive e análise B2B rápida.
- **contract-review-squad:** Validação automática da papelada de vendas antes da assinatura final do cliente.
