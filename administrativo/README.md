# Departamento: Administrativo

## Objetivo
Garantir o funcionamento contínuo das operações da Tecno IT, gerenciando suprimentos, estruturação de contratos básicos e rotinas corriqueiras de operação.

## Estrutura de Squads (AIOS)
Agentes como o `contract-review-squad` apoiam este departamento auxiliando em validação de compliance de contratos administrativos ou NDAs padrão.
